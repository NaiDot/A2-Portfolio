What I Built

งานนี้คือการสร้างเว็บ Learning Portfolio หน้าเดียว เพื่อแนะนำตัวเองและสรุปการเรียนรู้ในรายวิชานี้ครับ

องค์ประกอบสำคัญของหน้าเว็บมีดังนี้:

  • ส่วนหัวข้อและข้อมูลตัวฉัน
  • รูปโปรไฟล์ และคลิปวิดีโอแนะนำ
  • เนื้อหาอธิบายขั้นตอนการทำเว็บ
  • ลิงก์ไปยังเว็บไซต์ภายนอก

วิเคราะห์ Client / Server: เมื่อเปิดเว็บจากเครื่องคอมพิวเตอร์ของตัวเอง จะมีเฉพาะฝั่ง Client (คือเว็บเบราว์เซอร์) เท่านั้นที่ทำงาน โดยทำหน้าที่อ่านไฟล์ HTML/CSS มาแสดงผล และยังไม่มี Server เกิดขึ้น เพราะเราเปิดไฟล์โดยตรงจากเครื่อง ไม่ได้รันผ่านระบบ Server หรือเครือข่ายอินเทอร์เน็ตครับ

How I Built It

ขั้นตอนการสร้างเว็บ:

  1. วางโครงสร้างหน้าเว็บด้วย Semantic HTML เช่น header, main, section
  2. ใส่เนื้อหา ข้อความ รูปภาพ และลิงก์
  3. สร้างไฟล์ css/style.css เพื่อแต่งสีและจัดระยะห่างอย่างง่าย
  4. เช็กการเชื่อมโยงไฟล์รูปภาพและ CSS ด้วย relative path

เครื่องมือและแหล่งข้อมูลที่ใช้:

  • โปรแกรม Visual Studio Code ในการเขียนโค้ด
  • ค้นหาแท็ก HTML จากเว็บไซต์ W3Schools
